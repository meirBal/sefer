# עימוד ספר — כתב אשורי

Word → ספר מעומד בכתב תורה, לשמירה ב-Word או PDF. רץ כולו בדפדפן (ללא שרת, ללא עלות): `https://meirbal.github.io/sefer/`

## זרימה
קובץ ‎.docx‎ → תצוגת מקור → **בצע** → עמודים בגודל A5/A4, טקסט עיקרי בגודל הנבחר וכל השאר בפרופורציה, פונט ובחירת ניקוד/טעמים, כותרת רצה ומספור, השלמת עמודים לכפולה → שמירה (קובץ אחד / כל X עמודים / X קבצים / טווחים).

## מבנה
| קובץ | אחריות |
|---|---|
| `js/config.js` | גרסה, גדלי דף, ברירות מחדל, רשימת פונטים |
| `js/text.js` | טהור: ניקוד/טעמים, טוקנים, מספרים עבריים, תוכנית חלוקה |
| `js/docx-read.js` | קריאת Word: שרשרת סגנונות → גודל/הדגשה אמיתיים לכל ריצה (szCs לעברית) |
| `js/layout.js` | גאומטריה, מדידה ועימוד (פיצול פסקאות בחיפוש בינארי), הרכבת עמודים |
| `js/export.js` | Word: מקטע לכל עמוד (שבירות מדויקות + כותרת/כותרת תחתונה לכל עמוד) · הורדה · הדפסה |
| `js/stretch.js` | יישור סת"ם: מתיחת ם/ת/ה סופית אחת בשורה (גג ובסיס בלבד), שמות קודש מוגנים; רק בתצוגה/הדפסה/PDF |
| `js/print.js` | סידור חוברת/קונטרסים (ימין-לשמאל), דף בדיקה דו-צדדי, תצוגת הדפסה, PDF מוכן (רינדור הדפדפן → תמונה דחוסה, אפור או שחור-לבן 600) |
| `js/fontfile.js` | קובץ פונט: שם אמיתי ורישיון הטמעה מתוך הקובץ, ייבוא מהמחשב (Chrome/Edge), הטמעה בקובץ Word |
| `js/search.js` | חיפוש בספר המעומד: מתעלם מניקוד וטעמים, מקף = רווח; סימון בלי לשנות את הטקסט |
| `js/app.js` | מצב, טופס הגדרות, פונטים, עורך עמוד, חלון שמירה |
| `css/book.css` | ממשק + גאומטריית הדף (משותפת למסך, למדידה ולהדפסה) |
| `vendor/` | JSZip 3.10.1 · פונט Frank Ruhl Libre (OFL) מובנה — עובד בלי אינטרנט |
| `css/fonts.css` | הגדרת הפונטים המובנים |
| `scripts/` | release / rollback |
| `tests/` | `node book/tests/text.test.mjs` · `node book/tests/smoke.mjs` (דפדפן + בדיקת עימוד Word מול LibreOffice) |

## עקרון התאמה ל-Word
גובה שורה מדויק (exact) וגדלים בחצאי נקודה זהים במסך ובוורד; כל עמוד הוא מקטע נפרד ולכן העמוד נגמר בדיוק איפה שבתצוגה. השוליים התחתונים בוורד קטנים בשורה — מרווח ביטחון לשבירת שורה שונה מעט.

## פונט סת"ם (גוטמן)
Guttman Stam מגיע עם Office ואסור להפיץ אותו — לכן הוא לא נמצא באפליקציה עצמה. כל משתמש מכניס אותו פעם אחת מהעותק שלו:
במחשב — כפתור "ייבוא גוטמן סת"ם מהמחשב" (Chrome/Edge); בטלפון — לשלוח לעצמכם את הקובץ מ-`C:\Windows\Fonts` ולבחור ב-"📁 הוספת קובץ פונט".
הפונט נשמר באפליקציה, מוטמע ב-PDF, ומוטמע בקובץ ה-Word (כשרישיון הפונט מתיר) — כך Word מציג אותו גם במכשיר שאין בו את הפונט.
חלופה חינמית: Stam Ashkenaz CLM (Culmus).
